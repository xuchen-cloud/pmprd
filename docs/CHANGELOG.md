# 版本变更

## 0.1.12

- PRD 收起后，“打开 PRD”位于交互工具栏最右端、缩放控件之后。修正原因是按钮原先处于 DOM 首位；同时保持视觉顺序与键盘顺序一致。
- 补充宽/窄窗口收起展开、键盘访问及业务输入保留的浏览器回归检查。
- 整理公共仓库范围、开发说明和新电脑安装流程；插件继续内置两份 skill。
- 新增隔离发布打包命令，输出 `.tgz`、SHA-256 和安装说明，不改写本机已链接插件的构建文件。

## 0.1.11

- DSH 与外部 Agent 共用直接修改提示词；按需读取局部材料，通过一次 `finish` 完成交付。
- 支持默认更新当前文件或显式另存版本、局部 PRD diff、完成意见处理、冲突保护与取消后的迟到提交拒绝。
