# 版本变更

## 0.1.13

- 表格行列悬浮抓手和紧凑菜单，支持新增、删除行列；合并与拆分按选区能力显示，表头切换仅在首行提供。
- 统一文本、表格与图片的右键菜单；收紧字号、行高与分隔线，插入和删除操作使用图标分组。
- PRD 工具栏固定在正文滚动区域上方，缩小高度；修复列边界悬浮时的表格高度跳动。
- 图片居中展示，支持轻量角落抓手等比缩放、键盘微调及撤销；右键查看原图、下载和删除。原图在编辑器内预览，适配 DSH 桌面端。
- 图片保存到文档内资源区，Markdown 只保留短引用及尺寸；重复图片去重，保存重开及离线导出可用，历史不重复存储图片数据。
- 修复 AI 意见提交与动态目标到源码的定位，纳入此前提交的修改。
- 修复文件仅有系统元数据变化时误报保存冲突；正文冲突与写入并发检查继续生效。
- 更新安装及升级指令，支持让另一台电脑的 DSH 通过内置插件管理工具自行更新。

## 0.1.12

- 删除旧版根目录 skill、前端抽离模板、配套截图与旧文档；新版本使用的上游参考资料保留在 `skills/opentiny-ux/references/`。
- 提供公开 GitHub Release 安装包和可直接发给 DSH 的安装指令。

- PRD 收起后，“打开 PRD”位于交互工具栏最右端、缩放控件之后。修正原因是按钮原先处于 DOM 首位；同时保持视觉顺序与键盘顺序一致。
- 补充宽/窄窗口收起展开、键盘访问及业务输入保留的浏览器回归检查。
- 整理公共仓库范围、开发说明和新电脑安装流程；插件继续内置两份 skill。
- 新增隔离发布打包命令，输出 `.tgz`、SHA-256 和安装说明，不改写本机已链接插件的构建文件。

## 0.1.11

- DSH 与外部 Agent 共用直接修改提示词；按需读取局部材料，通过一次 `finish` 完成交付。
- 支持默认更新当前文件或显式另存版本、局部 PRD diff、完成意见处理、冲突保护与取消后的迟到提交拒绝。
