# 合成评审示例

`interaction-demo.ux.html` 是不连接后端的保存/弹窗样例，供本地开发和浏览器测试使用。可填写名称、保存、打开预览，再关闭弹窗。

它包含一条长期交互说明和一条示例修改意见：将主按钮“保存草稿”改为“保存并继续”，保留原有保存功能。修改意见 ID 为 `ann-demo-rename-save`，说明 ID 为 `ann-demo-name-explanation`。

用工作台或 DSH 打开文件以查看 PRD 和标注；通过“导出完整评审 HTML”生成可交接的离线只读页面。直接用浏览器打开 `.ux.html` 只显示业务原型。建议先复制文件再实际评审。

本目录中的其他本机稿件和导出副本不发布到源码仓库，也不属于构建依赖。
