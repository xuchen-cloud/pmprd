# 按当前任务选择交互模式

## 页面与导航

依据任务选择列表、详情、表单、设置、仪表盘、流程页或独立工具。按信息结构配置导航；切换后同步 current、标题与内容，返回时保留筛选条件和编辑草稿。涉及内容丢失时确认。链接对应实际区域，锚点滚动位置为固定标题预留空间。

## 表单与配置

使用清晰标签，按字段依赖处理启用、清空与保留。校验在字段附近显示，并将焦点定位到首个错误项。打开编辑时复制草稿，取消时还原，保存后更新展示。日期、范围、多选、级联、树选与穿梭按具体流程实现。选择弹层可使用原生控件；需要精确视觉复现时，按对应主题实现所需部分。

## 列表与数据表格

筛选后回到第一页，空结果提供清除筛选入口。排序、全选、分页与批量操作范围对应实际数据。根据业务任务配置工具栏，每个可见操作提供明确结果。按数据规模选择直接渲染或虚拟滚动，展示可信示例与真实数值比例。

## 详情、流程与反馈

长内容按阅读顺序组织。标签页切换视图，折叠面板展示次级信息，步骤条表达业务阶段。弹窗适合聚焦短任务，抽屉适合保留上下文的查看与编辑，大任务使用独立页面。保存成功提供就地状态或短提示，失败给出恢复动作，进度与当前状态同步。删除与覆盖等操作按影响提供确认。

## 上传与本地数据

文件选择 → 校验 → 清单或预览 → 处理 → 确认。文件类型、大小和数量按当前需求配置。拖拽、移除与重试均提供实际结果；模拟解析在演示说明中注明。网页资料通过链接列表与本地示例内容展示。

## AI 辅助

按任务选择预填字段、内联建议、搜索、对话或结果预览，外观参照 `navigation-and-ai.md`。

异步流程采用 idle → working → ready/error。加载立即反馈，处理期间保持单次提交，并提供取消或重试。取消时终止当前任务、保留上次成功结果。需要对照时保留版本，需要审核时区分预览与应用。按支持的指令更新结果；需要补充信息时保留输入并给出明确提示。Enter 发送结合 event.isComposing 区分中文输入法候选确认。

## 草稿与演示状态

按需求决定是否跨刷新保留草稿。使用 localStorage 时配置命名空间、try/catch 与重置入口。清楚表达本地模拟结果；演示范围集中说明一次。根据评审需要，通过折叠的原型说明选择异常状态。
